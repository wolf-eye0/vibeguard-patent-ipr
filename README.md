## 5. Rapid-Fire Objection Defense (Faculty Panel Cheat Sheet)

| Anticipated Committee Objection | Target Speaker | Verbatim 15-Second Defense Punchline |
|---|---|---|
| *"Is this just software on an ESP32? Doesn't Section 3(k) reject computer programs?"* | **ParadoxPete** | *"No. Under the 2017 CRI Guidelines and Delhi High Court precedent in Ferid Allani, Section 3(k) only bars software per se. Our claims are legally anchored to physical SPI Mode 2 registers, Welford hardware memory buffers, and physical GPIO trip circuits producing a direct technical effect."* |
| *"Tractian and SKF already do vibration monitoring. How are you novel?"* | **Archa** | *"Tractian requires continuous cloud streaming, and SKF Axios uses fixed factory thresholds. VibeGuard introduces autonomous on-device Quadrature Tare subtraction that calibrates in 15 seconds to any dynamic mounting substrate without sending raw data to the cloud."* |
| *"Do you have a working physical prototype or only simulations?"* | **Sreehari** | *"We have a fully fabricated physical testbed running live today: an N20 motor rig with precision 3D mounts, ADXL345 sampled at 800 Hz via 4-wire SPI Mode 2, and real-time NVS calibration demonstrated on our local telemetry dashboard."* |
| *"Why does Embodiment 2 cover wayside acoustic monitoring?"* | **Sreeprada** | *"Embodiment 2 extends our rotordynamic tracking to moving industrial assets (trains, overhead conveyors) using analytical CPA zero-crossing kinematics to eliminate Doppler shift without requiring expensive active tachometers."* |
